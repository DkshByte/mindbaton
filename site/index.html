Cloud
None. It runs on your hardware and keeps everything in your data folder.
Account with us
None. Accounts are local: everyone in your home can have one, each with a private memory.
Telemetry
None. Nothing phones home.
What leaves
Nothing by default. Add an AI key (free Gemini or Groq, or your own paid OpenAI or Claude key) and only the text for a summary, a topic name or an answer goes to that provider.
Secrets
API keys and passwords you paste into a chat are blanked out before anything is saved.
Forgetting
One click on any memory, or ask an AI to forget over MCP. It stays forgotten, even after a full rebuild.
Lock-in
Export everything as JSON, Neo4j Cypher or GraphML whenever you like.
Open ports
Not needed. Away from home, use Tailscale or Cloudflare Tunnel, never your router.

Install

You need a computer that stays on, like a home server, a NAS, a Mac mini or your laptop, with Python 3.9 or newer, or Docker. Nothing else.

  1. Run this in a terminal on the computer that stays on.

    git clone https://github.com/DkshByte/mindbaton && cd mindbaton && ./install.sh

  2. The installer checks Python, asks for your name and a password, offers free AI keys (skip them if you like; paid OpenAI and Claude keys can be added later in Setup) and connects the AI tools it finds.

  3. Open the link it prints, or scan its QR code with your phone, and sign in.

  1. Start it.

    git clone https://github.com/DkshByte/mindbaton && cd mindbaton && docker compose up -d

  2. Get your one-time setup code. It proves you're the owner, so nobody else on your network claims it first.

    docker compose logs mindbaton | grep "Setup code"

  3. Open http://<this computer>:3004/?code=<the code> and choose your password.

Then add the browser extension. Edge and Brave install it from the Chrome Web Store too. Setup ticks each AI as it connects.

Questions

Do I need an AI key or a graphics card?

No. Understanding is plain rules and a built-in table of word meanings, so it works offline on any computer. With 12 GB of memory or more, Mindbaton's own small model (1.3 GB, trained only on made-up examples) also reads what the rules miss, on that computer. An AI key is optional and only makes summaries and topic names nicer: a free Gemini or Groq key, or for the best results your own paid OpenAI or Claude key, which stops at a monthly limit you set.

Does anything I say leave my computer?

Not by default. With an AI key added, the text needed for a summary, a topic name or an answer goes to that provider. Leave the key out and nothing does.

What happens when a chat hits its limit?

Mindbaton turns the chat into a hand-off pack: the goal, decisions, open questions, exact names and code, and the latest messages word for word. Give it to another AI and it carries on from the last message.

Can I bring what ChatGPT already remembers?

Yes. Setup gives you one prompt to paste into ChatGPT, Claude, Gemini and the others. Paste the answer back, check each fact, and import. Coding agents' memory files come in when you connect them.

Can my family use it too?

Yes. Make an account for each person in your home. Each one has its own password and its own private memory, and nobody sees anyone else's.

Can I reach it away from home?

Yes, over HTTPS with Tailscale, Cloudflare Tunnel or your own reverse proxy. Never open the port on your router.

How do I get rid of it?

python3 mindbaton.py uninstall removes what it added to your AI tools and stops the service. Add --purge to delete your memories too.

# Mindbaton

> One private memory for ChatGPT, Claude, Gemini, Claude Code, Cursor and every other AI you use — running on your own computer. Free and open source (AGPL-3.0).

Mindbaton is a local-first memory daemon and MCP server that connects all AI chat interfaces, coding agents, and IDEs to a single private context store. When you talk to one AI, Mindbaton extracts facts, preferences, and decisions. When another AI needs context, it accesses the same memory over MCP or browser shortcuts. When a chat hits its context limit, Mindbaton packages the session into a compact handoff pack (sized to a token budget you set, from 200 to 12,000) so another model carries on from your last message.

## Core Architecture
- **Zero Cloud / Local-First**: Runs on Python (stdlib only) and SQLite. No cloud accounts, external databases, or subscriptions.
- **Embedded Natural Language Understanding**: 256-dimensional semantic embeddings and rules-based entity extraction run locally with zero API keys or GPU requirements.
- **Multi-Client Sync**: Captures context from browser chats via a lightweight browser extension and from IDEs/coding agents via MCP.
- **Baton Handoff Protocol**: Converts long conversations into structured continuation packs containing goals, decisions, open questions, code symbols, and verbatim recent turns.
- **Privacy & Security**: Automated redaction of API keys, tokens, and passwords prior to disk write. Data never leaves your network unless explicitly forwarded to an optional inference provider.

## Model Context Protocol (MCP) Tools

Mindbaton exposes an MCP server for coding agents (Claude Code, Cursor, Windsurf, Zed, OpenCode, Antigravity, Claude Desktop) and custom connectors:

- `context`: Retrieve briefing about the user, preferences, and topic-specific background.
- `recall`: Natural-language semantic search across all memories across all AIs.
- `remember`: Save a lasting fact or preference directly into memory.
- `profile`: Structured summary of user identity, active projects, and preferences.
- `handoff`: Generate a continuation pack for the active or specified chat session.
- `sessions`: List recent conversations across all connected AI tools.
- `save_conversation`: Persist chat turns to enable cross-model continuation.
- `forget`: Delete a specific memory by ID.

### MCP Configuration Example

Add to your MCP settings file:
```json
{
  "mcpServers": {
    "mindbaton": {
      "command": "python3",
      "args": ["/path/to/mindbaton/mcp_stdio.py"],
      "env": {
        "MINDBATON_URL": "http://localhost:3004",
        "MINDBATON_TOKEN": "mb_xxxxxxxx"
      }
    }
  }
}
```

Or connect directly over streamable HTTP: `POST http://localhost:3004/mcp` with `Authorization: Bearer mb_xxxxxxxx`. Responses are JSON; there is no SSE stream.

## HTTP API Reference

- `GET /health` - System health, version, and auth status (unauthenticated)
- `GET /recall?q={query}&k={count}` - Semantic search across memories
- `GET /context?q={topic}&budget={tokens}` - Formatted LLM prompt context injection
- `GET /profile` - Full user profile grouped by category
- `GET /sessions` - Recent conversation sessions with token fullness metrics
- `GET /handoff?session={id}&budget={tokens}` - Structured handoff continuation pack
- `POST /mcp` - Standard Model Context Protocol endpoint
- `POST /capture` - Ingest message from browser extension (auto-redacts secrets)
- `POST /remember` - Save explicit memory fact
- `DELETE /node/{id}` - Permanently erase memory item
