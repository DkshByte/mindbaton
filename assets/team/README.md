# Team Baton empty-state art

`baton-together.png` was generated with the built-in image generation tool using
`assets/app-512.png` as the character reference. It appears only in project and
client empty states, following DESIGN.md's Baton guidance.

Prompt: Create two Mindbaton Baton characters together on a truly transparent
background. Preserve the reference's elongated warm-white capsule silhouette,
slight right lean, and two black pill eyes. One character sits slightly behind
and smaller. Crisp monochrome illustration with subtle matte volume; warm white
#eeeeec and charcoal #111110. Centered composition with generous margins, suitable
for a small empty state in a Geist/graphite app. No text, limbs, accessories,
colored accents, backdrop, halos, or replacement app icon.
