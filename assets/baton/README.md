# Baton illustration collection

12 new situation-specific illustrations, plus the original team pair at
`../team/baton-together.png`. Generated with the built-in image generation tool,
using that original illustration as the character and material reference.

Open `index.html` directly or through your Mindbaton server to see every illustration and switch
the preview between graphite, light, and a transparency checkerboard.
`manifest.json` records each filename, intended situation, and full prompt.
`baton-collection.zip` includes all 13 transparent PNGs and the manifest.

Use these at meaningful pauses: empty states, first-run welcome, confirmations,
and recoverable connection states. Keep them small (roughly 96–160px), accompany
them with real text and an appropriate action, and use empty alt text when the
nearby copy already explains the state. Keep the app's existing vector brand
marks and interface icons. These illustrations are supporting assets, not status
indicators or replacements for the logo.

The collection is available for the whole app; the gallery does not automatically
insert every illustration into live screens.
